# VOID Roadmap

VOID aims to become a focused Hyprland desktop suite: darker, lighter, and more personal than a generic dotfiles dump.

## Near Term

- Make the installer fully first-run safe on EndeavourOS and clean Arch.
- Add a real theme switcher for palette, opacity, wallpaper, Waybar, Rofi, Kitty, GTK, Qt, SDDM, and fastfetch.
- Add opacity presets: solid, glass, ghost, and focus.
- Add a wallpaper selector that regenerates matching accent colors.
- Add a launcher selector for drun, run, clipboard, emoji, power, screenshot, audio, Wi-Fi, and Bluetooth menus.
- Add a health check command that validates packages, config syntax, keybinds, missing assets, and service status.

## HyDE Parity Targets

- One-command install with explicit backup and restore.
- Optional extra package list for user apps.
- Theme packs that can be installed, selected, and reverted.
- SDDM theme install with the active wallpaper.
- systemd-boot polish for machines that do not use GRUB.
- VM test flow that boots directly into a usable Hyprland preview.

## VOID Differentiators

- Monochrome-first design with carefully tuned transparency instead of heavy color palettes.
- Small, readable shell scripts over a large framework.
- Conservative host changes with clear backups.
- Dark terminal, clean fastfetch, and security-tool friendly defaults.
- Brave, Zen, Firefox, Chromium, Thunar, Dolphin, Codex, Antigravity, and common Wayland utilities treated as first-class apps.
